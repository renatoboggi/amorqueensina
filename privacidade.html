Política de Privacidade do Amor que Ensina Publicador

Vigente desde 20/10/2026.

O que é

O Amor que Ensina Publicador é uma ferramenta de uso interno, usada só pelo responsável do canal Amor que Ensina no próprio computador. Não é oferecida ao público.

Dados acessados

Com a autorização do titular da conta Google, a ferramenta acessa, pela API do YouTube e pela API do YouTube Analytics, os dados do próprio canal Amor que Ensina: envio e edição de vídeos, dados dos vídeos e estatísticas de visualização. Não acessa dados de outros usuários, de espectadores ou de crianças.

Uso e armazenamento

Os dados são usados só para publicar os vídeos do canal e acompanhar o desempenho deles. A chave de acesso fica guardada apenas no computador do responsável. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
